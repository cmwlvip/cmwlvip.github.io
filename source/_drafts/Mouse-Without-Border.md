## 概述

本教程系统介绍 **Mouse Without Borders**（中文译名：无界鼠标）软件的安装、配置与使用方法，适用于需通过**单套键盘鼠标同步操控多台 Windows 主机**的技术场景。  

该软件由微软开发并官方发布，**完全免费、无广告、无功能限制**，支持最多 **4 台 Windows 主机**之间的无缝鼠标穿越、键盘共享、剪贴板同步（复制/粘贴跨机生效）及快捷键透传。  

> **重要说明**：  
> - 本软件仅支持 **Windows 7 及以上版本操作系统**（推荐 Windows 10 / Windows 11）；  
> - 所有主机须处于**同一局域网内**（即连接同一路由器或交换机）；  
> - 各主机防火墙需允许 `MouseWithoutBorders.exe` 的入站与出站通信；  
> - **严禁从非官方网站下载**，以防捆绑恶意软件。

## 安装流程（所有主机通用）

### 通用安装步骤

1. 双击运行下载所得 `MouseWithoutBordersSetup.exe`；  
2. 在安装向导界面点击 **Next**（下一步）；  
3. 勾选 **I accept the license terms**（我接受许可条款），点击 **Next**；  
4. 保持默认安装路径，点击 **Install**；  
5. 安装完成后，点击 **Finish**（完成）；  
6. 若未自动启动主程序，可在桌面找到图标 `Mouse Without Borders`，**右键选择“以管理员身份运行”**（推荐首次运行启用此选项，确保网络权限）。

> **注意**：安装过程无需联网验证，不收集用户数据，不修改系统关键设置。

## 主机配置与组网

### 基本概念定义

- **主控主机（Primary PC）**：作为控制源的主机，其键盘鼠标输入将被广播至其他主机；  
- **受控主机（Secondary PC）**：接收主控主机输入信号的主机，自身输入设备默认被屏蔽（可手动切换焦点）；  
- **安全码（Security Code）**：16 位唯一字符串，用于主机间身份认证与加密通信；  
- **主机名（Computer Name）**：Windows 系统属性中设定的计算机全名（非 IP 地址），必须准确填写。

### 配置主控主机（第一台）

1. 启动软件后，选择 **Yes**；  
2. 在安全码输入框中，**严格输入 16 位字符**（示例：`A000000000000000`）,用户名随便输入，如`123456`,点击确定，此时连接失败是正常的，再点**NO**就可以看到安全码就出来了，主机名默认就是电脑主机名。
    ![2026-06-05-16-01-59.png](2026-06-05-16-01-59.png)
   > **重点知识点**：安全码必须为**大于16个ASCII 字符**（支持大小写字母、数字、常见符号），不可少于16位，否则连接失败。  
3. 点击左上角 **←（返回）**，这时候你想要的安全码就设置好了，当然，也可以直接点击**NO**，系统会随机给你生成安全码，就是复杂难输入。
4. 记录当前主机的安全码与主机名，供后续受控主机配置使用。

### 配置受控主机（第二台及以后）

1. 在目标受控主机上启动软件；  
2. 选择 **Yes**，直接输入第一台主机的安全码和主机名；
3. 点击 **Link**，即可配置成功。
   ![2026-06-05-16-10-11.png](2026-06-05-16-10-11.png)
4. 点击 **Next** → 进入配置界面

> **关键校验点**：  
> - 连接成功后，主控主机软件界面将显示所有已连接主机的网格化布局（如 2×2 排列），拖动匹配主机真实物理布局；  
> - 鼠标移至屏幕边缘并持续停留约 0.5 秒，将自动平滑穿越至相邻主机桌面；  
> - 剪贴板内容（Ctrl+C / Ctrl+V）在所有已连接主机间实时同步。`win+v`是共享剪切板的。

## 多主机协同操作基本设置

![2026-06-05-16-15-40.png](2026-06-05-16-15-40.png)

### Switch between machines

- `Ctrl+Alt+F1`：鼠标快速定位至1屏
- `Ctrl+Alt+F2`：鼠标快速定位至2屏

### Toggle Easy Mouse

通过此选项可以实现鼠标只在一台主机生效，防止鼠标跳出边界，锁定鼠标按一次快捷键，解锁在按一次也可以，建议设置为`Ctrl+Alt+Z`，有键位冲突再改成其他的即可。

搭配`Switch between machines`效果更佳。
